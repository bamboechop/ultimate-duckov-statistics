# World time text initialization

The 2560x1440 screenshot after Harmony restoration proves that Overview World time still overflowed. It supersedes the earlier broad user confirmation of that layout. Current Diagnostics returning to green is a separate successful restoration check; historical incomplete-capture text must still fit.

Installed TMP initializes its font size to -99. When a new component first enters an active hierarchy, Awake calls LoadDefaultSettings. While that sentinel remains, TMP resets wrapping to the installed game setting, which is false. UDS created the World time label under the inactive shell and configured wrapping before activation, but assigned its font size only during later layout. The first activation therefore silently reset wrapping; the later actual-width measurement correctly measured an unwrapped label.

The factory now assigns the existing reference font size before activation. This avoids TMP's sentinel default reset and preserves the configured wrapping. Layout still assigns the scaled font size and grows the card from the actual-width preferred height. Text, font choice, evidence qualifiers and statistics are unchanged. No game setting or production visual validator is introduced.

The shell boundary now models TMP's first active-hierarchy transition and sentinel/default-wrapping behavior, including activation through parenting, and respects explicit newlines and the wrapping flag in its approximate measurement. Previously it always estimated wrapped height and omitted Awake. Both existing incomplete-sleep cases (2560x1440 and 720x480, with resize) fail at the wrapping assertion against the prior production source after correcting this boundary. The corrected production initialization makes them pass. This is lifecycle regression evidence, not native glyph or GPU simulation.

The independent native investigation is preserved at `artifacts/m18-worldtime-native-cause/report.md`, SHA-256 `5e35845af2b27628873d652463d6d5a285345769dc9fff3af286280012849e95`. It includes decompiled native setter/Awake/measurement contracts and the installed serialized TMP Settings object proving wrapping defaults to false. Completed delivery identities are recorded in the correction evidence; the user must still verify the corrected World time block at the reported resolution and after resize. Harmony can remain enabled for that check.
